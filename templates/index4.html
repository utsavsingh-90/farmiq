Query Demonstration

Execution of SELECT, JOIN, GROUP BY, Nested Subqueries, and Stored Procedures

JOIN + FILTER
High-Sustainability Recommendations
SELECT f.name, rg.region_name, c.crop_name, r.predicted_yield, r.expected_profit, r.sustainability_score FROM Recommendation r JOIN Land_Parcel lp ON r.land_id = lp.land_id JOIN Farmer f ON lp.farmer_id = f.farmer_id JOIN Region rg ON lp.region_id = rg.region_id JOIN Crop c ON r.crop_id = c.crop_id WHERE r.sustainability_score > 80;
💡 4-table JOIN showing relational power; filters on business rule (score > 80)
BETWEEN + CROSS JOIN
Crop–Soil Suitability Match
SELECT c.crop_name, st.pH, st.nitrogen_level, CASE WHEN st.pH BETWEEN cr.min_ph AND cr.max_ph AND st.nitrogen_level BETWEEN cr.min_nitrogen AND cr.max_nitrogen THEN 'SUITABLE' ELSE 'NOT SUITABLE' END AS suitability FROM Soil_Test st CROSS JOIN Crop c JOIN Crop_Requirement cr ON c.crop_id = cr.crop_id WHERE st.land_id = 1;
💡 CROSS JOIN + CASE expression for rule-based classification
GROUP BY + AVG
Avg Profit by Crop Type
SELECT c.crop_type, COUNT(*) AS total_recs, ROUND(AVG(r.expected_profit),2) AS avg_profit FROM Recommendation r JOIN Crop c ON r.crop_id = c.crop_id GROUP BY c.crop_type ORDER BY avg_profit DESC;
💡 Aggregation across crop categories
NESTED SUBQUERY
Lands Above-Average Yield
SELECT lp.land_id, f.name, r.predicted_yield FROM Recommendation r JOIN Land_Parcel lp ON r.land_id = lp.land_id JOIN Farmer f ON lp.farmer_id = f.farmer_id WHERE r.predicted_yield > ( SELECT AVG(predicted_yield) FROM Recommendation );
💡 Correlated subquery; compares against global average
STORED PROCEDURE
GetSuitableCrops(land_id)
CALL GetSuitableCrops(5); -- Returns crops where soil pH/N -- is within crop requirements
💡 Encapsulates complex matching logic into a single call
